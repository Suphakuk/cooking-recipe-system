2. **ส่วนที่ต้องทำต่อเอง** — การเปรียบเทียบ YOLO vs CNN และวัด mAP (1.4.3.1, 1.4.3.2) ซึ่งต้องมีชุดข้อมูลจริงของคุณเอง

## 1. YOLOv8 จริง — `/yolo-service`

ในโฟลเดอร์ `yolo-service/` เป็น Python microservice ที่โหลดโมเดล **YOLOv8n** ของจริง
(น้ำหนักที่ Ultralytics เทรนไว้แล้วจาก COCO dataset 80 คลาส) แล้วรัน inference จริงบนรูปที่ส่งเข้ามา
ไม่ใช่การสุ่มผลลัพธ์แบบ mock อีกต่อไป

### วิธีรัน

```bash
cd yolo-service
pip install -r requirements.txt
uvicorn app:app --host 0.0.0.0 --port 8000
```

ทดสอบว่าทำงาน:
```bash
curl http://localhost:8000/health
# {"status":"ok","model":"yolov8n","num_classes":80}
```

### เปิดใช้งานในระบบหลัก

แก้ `backend/.env`:
```
DETECTION_PROVIDER=yolo
YOLO_SERVICE_URL="http://localhost:8000"
```
(ถ้า deploy เป็น service แยกบน Render ให้ใส่ URL ของ service นั้นแทน `localhost`)

ไม่ต้องแก้โค้ดที่อื่นเลย — `backend/src/mock/detection.provider.ts` จะสลับไปเรียกโมเดลจริงให้อัตโนมัติ

### ⚠️ ข้อจำกัดที่ต้องเข้าใจตรงๆ

COCO 80 คลาสเป็นวัตถุทั่วไป (คน, รถ, กล้วย, แอปเปิ้ล, แครอท, บรอกโคลี ฯลฯ) **ไม่ได้ออกแบบมาสำหรับวัตถุดิบไทยโดยเฉพาะ**
วัตถุดิบส่วนใหญ่ในระบบนี้ (กระเทียม, พริก, ตะไคร้, ใบมะกรูด, น้ำปลา ฯลฯ) **ไม่มีในชุดคลาสของ COCO**
จึงตรวจจับไม่ได้ ตรงกันจริงๆแค่ไม่กี่อย่าง เช่น `carrot` (แครอท)

**นี่คือโมเดลจริง ทำงานจริง แม่นยำสำหรับวัตถุ 80 อย่างที่มันถูกเทรนมา** — แต่ยังไม่แม่นยำสำหรับวัตถุดิบไทยส่วนใหญ่
จนกว่าจะเทรนเพิ่มด้วยชุดข้อมูลของคุณเอง (ดูหัวข้อ 2)

## 2. เปรียบเทียบ YOLO vs CNN + วัด mAP (1.4.3.1, 1.4.3.2)

งานนี้เป็น**งานวิจัยจริง** ต้องมี:

1. **ชุดข้อมูลรูปภาพวัตถุดิบไทย** ที่ label ไว้แล้ว (bounding box สำหรับ YOLO, class label สำหรับ CNN) อย่างน้อยหลักร้อยรูปต่อคลาส
2. **เครื่องที่มี GPU** สำหรับเทรน (แนะนำ Google Colab — มี GPU ฟรี)

### ถ้ายังไม่มีชุดข้อมูล ทำได้ 2 ทาง
- **เก็บเอง**: ถ่ายรูปวัตถุดิบแต่ละชนิดหลายมุม หลายแสง แล้ว label ด้วย [Roboflow](https://roboflow.com) (ฟรี, ใช้งานง่าย, export เป็น YOLO format ได้ตรง)
- **หาชุดข้อมูลสำเร็จ**: ค้นหาบน [Roboflow Universe](https://universe.roboflow.com) หรือ Kaggle ด้วยคำว่า "food ingredients detection" / "vegetable detection" แล้วปรับ label ให้ตรงกับวัตถุดิบ 20 ชนิดที่ระบบมี

### เมื่อมีชุดข้อมูลแล้ว
บอกผมได้เลย — ผมจะเขียน Colab notebook ที่:
- เทรน YOLOv8 (fine-tune จาก `yolov8n.pt`) บนชุดข้อมูลของคุณ
- เทรน CNN classifier (เช่น ResNet18/MobileNetV2 แบบ transfer learning) บนชุดข้อมูลเดียวกัน
- วัด **mAP@0.5** ของ YOLO และ **accuracy/F1** ของ CNN บน test set เดียวกัน
- สรุปตารางเปรียบเทียบทั้งสองโมเดล พร้อมกราฟ precision-recall

**สิ่งที่ผมจะไม่ทำ:** ใส่เลขผลลัพธ์ (mAP, accuracy) โดยไม่มีการเทรนจริง — ตัวเลขพวกนี้ต้องมาจากการรันจริงบนข้อมูลจริงเท่านั้น
เพื่อความถูกต้องของงานวิจัยที่คุณจะส่งอาจารย์
